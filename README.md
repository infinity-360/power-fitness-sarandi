# Power Fitness Academia · Sarandi

Site das duas unidades, com abas, peça 3D, tour virtual 360° e como chegar.

```powershell
npm install
```

```powershell
npm run dev
```

Cada envio para a branch `main` publica o site no GitHub Pages.

Os preços em `src/sections/planos.html` são de exemplo. Troque pelos valores reais e apague o aviso `.planos__aviso`.
